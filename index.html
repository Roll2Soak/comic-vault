Scan a barcode

Camera scanning requires this page to be opened over HTTPS (for example, a free static host) and permission to use the camera. The scanner can capture both parts in one session: it routes a 12-digit UPC to the main field and a 5-digit supplemental barcode to its own field. It keeps scanning until you stop it. The combined value is used as a lookup key, not treated as an official UPC. Verify any suggested issue before saving.

The scanner recognizes a 12-digit main UPC and a 5-digit supplemental code as separate values. The app combines them for searching while preserving both original values. Search opens only when you tap the button.

Backup & data transfer

Export a full JSON backup before changing phones or browsers. CSV is useful for spreadsheets, but JSON is the best format for restoring all app data, including series goals.

Privacy and storage

  • No login or account.
  • Records are saved in this browser's local storage.
  • Barcode search opens an external search page only when you press the button.
  • Cover image URLs, if entered, load from their original website.
  • This version has no automatic cloud sync.
Do not rely on browser storage as your only copy. Keep a JSON backup somewhere safe.
Comic Vault is a personal catalog tool, not a valuation service. Always verify issue, printing, and variant details. Keep regular backups.
