Backup & data transfer

Export a full JSON backup before changing phones or browsers. CSV is useful for spreadsheets, but JSON is the best format for restoring all app data, including series goals.

Privacy and storage

  • No login or account.
  • Records are saved in this browser's local storage.
  • Barcode search opens an external search page only when you press the button.
  • Cover image URLs, if entered, load from their original website.
  • This version has no automatic cloud sync.
Do not rely on browser storage as your only copy. Keep a JSON backup somewhere safe.
Comic Vault is a personal catalog tool, not a valuation service. Always verify issue, printing, and variant details. Keep regular backups.
